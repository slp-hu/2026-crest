可逆仮名化プロトタイプ  /  VC 経路

テキストを使わずに、声を別人にして、鍵で本人に戻す

これまでのデモは、テキストと話し方から音声を合成する経路（TTS）で組んでいました。 同じ仕組みが、音声をそのまま別の声へ変換する経路（VC）でも成り立つことを示します。 変換にテキストもアライメントも要らないので、オンラインの API 利用にそのまま置けます。

01同じ発話を、4 とおりで聴く

話者を選ぶと、同じ発話の 4 版が並びます。棒は発話長です — VC 経路は原音の長さをそのまま保ちます。

対照も聴く（床 VC_self / 誤鍵 VC_mosK2）

03この 3 つを言う

  1. 方式は経路に依存しないVC 経路の正鍵 k = 3.71 は、TTS 経路の 3.84–3.93 とほぼ同じ水準。 擬似話者の作り方（主成分モザイク）がそのまま効いている。
  2. テキストもアライメントも要らない入力は音声だけ。だからクラウド API に音声を送る用途に、 そのまま挟める。
  3. 話し方は原話者のまま。ただし蓄積しない音色は完全に置き換わるが、話し方は残る。 その残余は発話を集めても強くならない — 深さを 25 倍にしても EER は 43.75% → 47.48% で動かない （本物のチャネルなら d′ が 3.16 倍になるはず）。

04言わないでおくこと

  • 「原録音は外に出ない」は VC 版では使えない。配布されるのは変換音で、原録音由来です。 言えるのは「音色は完全に置き換わっており、鍵がなければ誰にも辿れない」まで。
  • 話し方は仮名化していません。TTS 経路は話し方をチャネルとして扱えるので P_full を選べますが、VC 経路は原話者の話し方が常に素通しです。
  • この頁の音と数字は CSJ で撮った見本です。この方式が要るのは、 これから作られる、生音声のままでは配れないコーパスのほう。
  • 80 話者では EER の分解能が 0.6%。論文用の数字は 375 話者で取り直します。
